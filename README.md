# Mastering Mathematical Logic: Complete Edition

A free, self-study book that starts from absolute zero and goes through propositional logic, natural deduction, predicate logic, proof technique, metatheory (soundness, completeness, Gödel), automated reasoning, and a working logic engine you can build yourself.

**Read it online: https://swicherwich.github.io/cogito-ergo-sum/**

The page has a chapter sidebar, light, dark and paper themes, a dyslexia-friendly font option, and works on phones and tablets.

## Contents of this repository

| File | What it is |
| --- | --- |
| `index.html` | The book as a single self-contained web page (this is what GitHub Pages serves) |
| `mastering-logic-complete.md` | The same book as Markdown (source text, with its own table of contents) |
| `logic_engine_starter.py` | Reference starter kit for Chapter 8: parser, substitution, model checker, SAT solver, Fitch proof checker, resolution prover (Python 3.10+) |
| `test_starter.py` | 2,520 automated checks for the starter kit: `python3 test_starter.py` |
| `LICENSE` | CC BY-SA 4.0 |
